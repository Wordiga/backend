# 관광 콘텐츠 추천 알고리즘

## 공통 정책

- 추천 범위는 충청남도이며 일반 목록에서 행사·축제(`contentTypeId=15`)를 제외합니다.
- `theme`과 복수 `category` 필터는 관광공사 신분류 코드에서 변환한 화면 분류에 적용합니다.
- 축제는 `type=FESTIVAL`로 별도 조회합니다.
- 목록에는 `recommendationScore`만 제공하고, 점수 구성과 근거는 콘텐츠 상세에서 제공합니다.
- `POPULAR`, `SEASONAL`, `PERSONALIZED`는 생성한 후보 수를 `totalCount`로 사용합니다. `RELATED`는 상세 화면의 짧은 가로 목록이므로 합계를 제공하지 않습니다.
- 같은 점수 안의 개인화 결과는 날짜와 콘텐츠 ID로 정한 순서를 사용합니다. 같은 날 페이지 이동은 안정적이고 날짜가 바뀌면 노출 순서가 달라질 수 있습니다.

## POPULAR

점수순 시군구의 콘텐츠를 한 개씩 교차 배치하고, 같은 지역 안에서는 날짜 기반의 안정적인 순서를 사용합니다. 따라서 같은 날 페이지 이동 시 순서는 유지되지만 다음 날에는 선두 콘텐츠가 달라질 수 있습니다.

```text
지역 인기 점수 = 외지인 소비 강도 × 60% + 1박 체류 강도 × 40%
```

- 기준월: 매월 16일 이후 전월, 그 이전 전전월
- 외부 API: `areaTarExpDsList(2201)`, `areaTarSjrnDsList(2103)`, `areaBasedList2`
- 한계: 콘텐츠 자체 인기도가 아니라 콘텐츠가 속한 시군구의 점수입니다.

## SEASONAL

지역 수요 70%에 관광타입별 계절 적합도 30%를 더하고, 방문 월 기반의 안정적인 순서를 사용해 인기 추천과 선두 콘텐츠가 겹치는 비율을 줄입니다.

```text
계절 추천 점수 = 전년도 동월 지역 관광 서비스 수요 × 70% + 계절 적합도 × 30%
```

계절 적합도는 추가 외부 호출 없이 사용하는 서비스 정책값입니다. 봄은 관광지·여행코스, 여름은 관광지·축제·레포츠, 가을은 관광지·문화시설·여행코스, 겨울은 문화시설·레포츠·숙박에 100점, 나머지 유형에 50점을 적용합니다.

## PERSONALIZED

저장된 위시의 지역·대분류 비율, 방문 월의 계절 정책, 입력 연령대의 지역 적합도를 사용합니다. 연령 적합도는 동일 요청의 시군구별로 한 번 계산합니다.

```text
개인화 점수 = 위시 지역 비율 × 40% + 위시 대분류 비율 × 25% + 계절 적합도 × 20% + 연령 적합도 × 15%
```

- 위시가 없으면 천안 동남구·보령·태안을 기본 후보 지역으로 사용합니다.
- 위시 선호 비율은 서버 메모리 캐시에 저장하고 위시 변경 시 삭제합니다.
- 연령 적합도는 선택 연령대의 시군구별 관광객·소비 다양성 지수를 동일 비율로 평균합니다. 원천값이나 입력이 없으면 50점을 적용합니다. 콘텐츠별 연령 적합도는 제공하지 않습니다.
- `participantCount`는 숙박의 수용 가능 여부와 1인 예상 비용에 사용합니다. 수용 불가능한 숙박은 제외하며 수용 정보가 없는 숙박은 유지합니다. `capacitySatisfied=true`이면 수용 가능하다고 확인된 숙박만 남깁니다.
- 한계: 행동 로그나 협업 필터링을 사용하지 않으므로 개인화 정확도는 위시 데이터 양에 좌우됩니다.

## RELATED

- 콘텐츠 상세 하단에서 최대 요청 크기만큼 제공합니다.
- 관광공사 연관 관광지 이름을 `searchKeyword2`로 콘텐츠 ID에 연결합니다.
- 전체보기 화면이 없으므로 `totalCount`, `totalPages`는 `null`입니다.
- 원천 연관 관광지를 콘텐츠 ID로 연결하지 못하면 같은 시군구의 동일 카테고리를 우선한 후보로 대체합니다.
- 한계: 연관 API가 콘텐츠 ID를 주지 않아 이름 검색 호출이 필요합니다.

## FESTIVAL

- `GET /api/v1/tourism/contents/festivals?visitMonth=YYYY-MM`
- `visitMonth`의 1일부터 말일까지를 `searchFestival2`의 행사 시작일·종료일로 전달합니다.
- `contentTypeId=15`이며 해당 방문 월에 관람 가능한 축제만 반환합니다.
- 키워드 검색은 적용하지 않으며 충청남도와 선택한 시군구를 원천 API 요청에서 제한합니다.
- 일반 목록 및 일반 검색 결과에서는 축제를 제외합니다.

## 캐시

관광공사 공통·소개·반복·이미지 상세와 지역 통계 응답은 서버 메모리에 최대 10,000건, 6시간 TTL로 캐시합니다. 목록과 상세를 연속 조회할 때 동일 상세 API의 중복 호출을 줄이기 위한 캐시이며 영속 데이터가 아니므로 DB에는 저장하지 않습니다.
